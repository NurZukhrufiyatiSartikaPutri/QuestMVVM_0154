# Activity 6 – Form Pendaftaran Data Siswa

Project ini merupakan aplikasi Android sederhana menggunakan **Kotlin dan Jetpack Compose** untuk mengimplementasikan form input data siswa dan navigasi antarhalaman.

### Fitur Aplikasi
- Mengisi nama lengkap siswa.
- Memilih jenis kelamin (Laki-laki atau Perempuan).
- Mengisi alamat lengkap.
- Menampilkan data siswa yang telah diinput pada halaman Data Siswa.
- Navigasi kembali menggunakan tombol Back.
